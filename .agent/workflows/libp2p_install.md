1. Install the main libp2p package and its essential suite of transports, muxers, and security modules.

2. Run the following command:

```bash
npm install libp2p @libp2p/tcp @libp2p/websockets @libp2p/mplex @libp2p/noise @chainsafe/libp2p-gossipsub @libp2p/mdns @libp2p/kad-dht uint8arrays it-pipe
```
